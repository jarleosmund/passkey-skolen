# Passkey-skolen

Interaktivt kurs på norsk om passkeys for Windows 11-brukere i Microsoft 365. Kurset starter enkelt og går gradvis over til Entra ID-policy, Betinget tilgang og feilsøking. Hver leksjon har et sjekkpunkt med quiz og en alternativ forklaring.

**Åpne kurset:** https://jarleosmund.github.io/passkey-skolen/

## Innhold

1. **Grunnleggende:** hva en passkey er, Windows Hello, hvorfor det er tryggere
2. **Lagring:** Windows Hello, mobil, Microsoft Authenticator, sikkerhetsnøkkel, passordbehandlere
3. **Microsoft 365 i praksis:** Windows Hello for Business, registrering, bytte mobil, tapt enhet
4. **Avansert og for IT:** Entra ID-policy, Betinget tilgang, feilsøking, utrullingsplan

## Utvikling

`passkey-skolen.html` er kilden. Kjør `./build.sh` for å lage `index.html`, som er det GitHub Pages viser.
